# T20 — Create Accessibility Features

**Difficulty:** medium
**Weight:** 0.0244 (share of project budget)
**Reward:** 21.951 TNF + 0.002 TON

Implement accessibility features to ensure the website is usable by everyone. This should include:
- Adding alt text to images
- Ensuring keyboard navigation
- Implementing screen reader support
- Using proper color contrast
- Creating accessible forms
